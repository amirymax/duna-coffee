# Дюна — лендинг кофейни

Статический лендинг: `index.html` + `styles.css` + `script.js` + `assets/photos/`.
Сборка не нужна — можно открыть локально или залить на любой хостинг (GitHub Pages, Netlify).

## Локальный запуск
```
python3 -m http.server 8765
```
Затем http://localhost:8765

## Источник данных
Всё содержимое собрано с карточки заведения на Яндекс Картах
(`yandex.ru/maps/org/dyuna/95789220678`): название, адрес, телефон, часы,
особенности, полное меню с ценами, рейтинг 4,9 / 48 оценок, 40 отзывов
(на странице — 4 избранных, остальные 24 в модальном окне; тексты слегка сокращены без изменения смысла),
37 фотографий (скачаны в `assets/photos/`; на странице — 8, все 24 отобранных в модальном окне с фильтрами).

## Дизайн
Структура, типографика и тональность — по референсу gulyamov0003.github.io/yakkachinar:
нумерованные секции, Cormorant (заголовки) + Inter Tight (текст), тёмная база с золотом.
Палитра сдвинута в тёплый песочный под бренд «Дюна».

## Анимация (`motion.js`)
Параметры сняты с бандла референса и воспроизведены один-в-один, но без React/Framer —
на нативных transition + IntersectionObserver:

| Что | Параметры |
|---|---|
| Кривая | `cubic-bezier(.16, 1, .3, 1)` |
| Smooth scroll | Lenis `{ lerp .09, wheelMultiplier .95, allowNestedScroll }` |
| Fade-up | opacity 0 / y 32 → 1.1s, порог 0.2 |
| Заголовки | построчная маска, inner y 110% → 0, 1.25s, stagger .09s, порог 0.35 |
| Подписи секций | индекс .9s → линия scaleX 1.1s (+.1s) → текст (+.25s), порог 0.6 |
| Фото | clip-path inset(100% → 0) 1.6s + scale 1.24 → 1 за 2.3s |
| Параллакс | слой ±9%, сдвиг по прогрессу элемента в вьюпорте |
| Бегущая строка | 52s linear + маска по краям |
| Зерно | `.9s steps(4, end)` |
| Блик по логотипу | `brand-sheen-loop` 9s |
| Курсор | точка + кольцо 38px, lerp .38 / .14, состояния view и magnetic |
| Модальные окна | backdrop 0.5s, панель `y 36 / scale .985 → 0 / 1` за 0.8s, выход 0.55s, волна содержимого .045s |

Lenis лежит локально в `assets/vendor/` — внешних зависимостей во время работы нет.
При `prefers-reduced-motion: reduce` всё движение отключается, контент показывается сразу.

## Что стоит заменить перед публикацией
- Фотографии на профессиональную съёмку (текущие — пользовательские с Яндекс Карт).
- Проверить актуальность цен (Яндекс помечает меню как «давно не обновлялось»).
- Добавить встроенную карту и соцсети, если они есть.
